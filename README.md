# 🎵 Amazon Music Clone

A responsive Amazon Music Clone built using **HTML5** and **CSS3**. This project recreates the look and feel of Amazon Music with a clean UI and responsive design.

## 🚀 Features

- Responsive layout
- Hero banner
- Trending Songs section
- Playlists
- Album cards
- Hover effects
- Modern UI

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
